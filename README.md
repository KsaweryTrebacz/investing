# Doradca XAU/USD

Program, który co 15 minut mówi, czy według reguł warto kupić, sprzedać, czy czekać ze złotem (XAU/USD).
Łączy reżim dzienny (trend złota, dolar, realne rentowności) z sygnałem M15, pokazuje werdykt na lokalnym dashboardzie i wysyła powiadomienia na Telegram. Nie składa zleceń.

> Sygnały analityczne, nie porada inwestycyjna.
